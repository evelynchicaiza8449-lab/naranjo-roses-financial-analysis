# Diccionario de Datos - Naranjo Roses

| Campo | Tipo de Dato | Descripción |
| :--- | :--- | :--- |
| `anio` | Int | Año del registro de exportación |
| `hectareas_cultivadas` | Int | Superficie total dedicada al cultivo de rosas |
| `tallos_exportados` | Int | Cantidad total de tallos de rosas exportados |
| `precio_promedio_tallo_usd` | Float | Precio promedio de venta por tallo en USD |
| `costo_insumos_fertilizantes_usd` | Float | Gasto total en fertilizantes y agroquímicos en USD |
| `flete_aereo_usd` | Float | Costos de transporte logístico aéreo en USD |
| `mano_obra_usd` | Float | Costo total de personal y mano de obra en USD |
